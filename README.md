HTTP-запити і взаємодія з бекендом <br>
Щоб перевірити себе, переконайся, що ти знаєш: <br>
    у чому різниця між протоколами HTTP і HTTPS <br>
    основні HTTP-методи та як їх застосовувати <br>
    що таке CRUD <br>
    як взаємодіяти з бекендом <br>
Для організації коду використовуй модульність та синтаксис export/import. <br>
У файлі pixabay-api.js зберігай функції для виконання HTTP-запитів: <br>
    getImagesByQuery(query). Ця функція повинна приймати один параметр query (пошукове слово, яке є рядком), здійснювати HTTP-запит і повертати значення властивості data з отриманої відповіді. <br>
У файлі render-functions.js створи екземпляр SimpleLightbox для роботи з модальним вікном та зберігай функції для відображення елементів інтерфейсу: <br>
    createGallery(images). Ця функція повинна приймати масив images, створювати HTML-розмітку для галереї, додавати її в контейнер галереї та викликати метод екземпляра SimpleLightbox refresh(). Нічого не  <br>повертає. <br>
    clearGallery(). Ця функція нічого не приймає та повинна очищати вміст контейнера галереї. Нічого не повертає. <br>
    showLoader(). Ця функція нічого не приймає, повинна додавати клас для відображення лоадера. Нічого не повертає. <br>
    hideLoader(). Ця функція нічого не приймає, повинна прибирати клас для відображення лоадера. Нічого не повертає. <br>
У файлі main.js напиши всю логіку роботи додатка. Виклики нотифікацій iziToast, усі перевірки на довжину масиву в отриманій відповіді робимо саме в цьому файлі. Імпортуй в нього функції із файлів pixabay-api.js та render-functions.js та викликай їх у відповідний момент. <br>

Завдання — Пошук зображень <br>
Створи застосунок пошуку зображень за ключовим словом і їх перегляду в галереї. Додай оформлення елементів інтерфейсу згідно з макетом https://www.figma.com/file/m8k9NQV7qZrtYDCvxfD68B/%D0%94%D0%97-JavaScript?type=design&node-id=3-1009&mode=design&t=eCh8cUwdfWOakuAr-0 <br>
 <br>
Форма пошуку <br>
Додай в HTML файл розмітку форми. Форма складається з поля вводу для введення пошукового слова і кнопки з типом submit.   <br>
Користувач буде вводити рядок для пошуку в текстове поле, а за сабмітом форми необхідно виконувати HTTP-запит із цим пошуковим рядком. <br>
При натисканні на кнопку відправки форми, додайте перевірку вмісту текстового поля на наявність порожнього рядка, щоб користувач не міг відправити запит, якщо поле пошуку порожнє. <br>
 <br>
HTTP-запити <br>
Додай у проєкт бібліотеку Axios для написання коду, пов’язаного з HTTP-запитами. <br>
Для бекенду використовуй публічний API сервіс Pixabay. Зареєструйся, отримай свій унікальний ключ доступу і ознайомся з документацією. <br>
Список параметрів рядка запиту, які тобі обов'язково необхідно вказати: <br>
    key — твій унікальний ключ доступу до API. <br>
    q — слово для пошуку. Те, що буде вводити користувач. <br>
    image_type — тип зображення. Потрібні тільки фотографії, тому постав значення photo. <br>
    orientation — орієнтація фотографії. Постав значення horizontal. <br>
    safesearch — фільтр за віком. Постав значення true. <br>
У відповіді буде об’єкт із декількома властивостями, в одному з яких (hits) буде масив об’єктів із зображеннями, що задовольнили критерії параметрів запиту. <br>
Обов’язково винеси функції для HTTP-запитів у файл pixabay-api.js у папці js. Це хороша практика та можливість відпрацювати модульний підхід до розробки. <br>
Якщо бекенд повертає порожній масив, це означає, що нічого підходящого не було знайдено. У такому випадку відображай повідомлення з текстом: <br>
Sorry, there are no images matching your search query. Please try again! <br>
Для показу повідомлень використовуй бібліотеку iziToast. Щоб підключити CSS-код бібліотеки до проєкту, необхідно додати ще один імпорт, окрім того, що описаний у документації. <br>
// Описаний у документації <br>
import iziToast from "izitoast"; <br>
// Додатковий імпорт стилів <br>
import "izitoast/dist/css/iziToast.min.css"; <br>

Галерея і картки зображень <br>
Елемент галереї (список однотипних елементів <ul class=”gallery”>) уже має бути в HTML-документі. Після виконання HTTP-запитів у нього потрібно додавати розмітку карток зображень. <br>
Кожне зображення описується об'єктом, з якого тебе цікавлять лише такі властивості: <br>
    webformatURL — посилання на маленьке зображення для списку карток у галереї <br>
    largeImageURL — посилання на велике зображення для модального вікна <br>
    tags — рядок з описом зображення. Підійде для атрибута alt <br>
    likes — кількість вподобайок <br>
    views — кількість переглядів <br>
    comments — кількість коментарів <br>
    downloads — кількість завантажень <br>
Перед пошуком за новим ключовим словом необхідно повністю очищати вміст галереї, щоб не змішувати результати запитів. <br>
 <br>
Бібліотека SimpleLightbox <br>
Додай відображення великої версії зображення з бібліотекою SimpleLightbox для повноцінної галереї. <br>
Щоб підключити CSS-код бібліотеки до проєкту, необхідно додати ще один імпорт, окрім того, що описаний у документації. <br>
// Описаний у документації <br>
import SimpleLightbox from "simplelightbox"; <br>
// Додатковий імпорт стилів <br>
import "simplelightbox/dist/simple-lightbox.min.css"; <br>
    У розмітці необхідно буде обгорнути кожну картку зображення в посилання, як зазначено в документації в секції Markup. <br>
    Бібліотека містить метод refresh(), який обов'язково потрібно викликати щоразу після додавання нових елементів до галереї. <br>
Робота модального вікна пов'язана з самою галереєю, тому використання бібліотеки SimpleLightbox і методу екземпляру refresh() буде доцільним у файлі render-functions.js. <br>

Індикатор завантаження <br>
Додай елемент для сповіщення користувача про процес завантаження зображень із бекенду. Завантажувач має з’являтися перед початком HTTP-запиту та зникати після його завершення. <br>
Замість банального тексту, як це реалізовано в демовідео, використовуй бібліотеку з гарними індикаторами завантаження css-loader. Відеоінструкція з використання цієї бібліотеки є в README.md їхнього репозиторію. <br>
На що буде звертати увагу ментор при перевірці: <br>
    Домашня робота містить два посилання: на вихідні файли і живу сторінку на GitHub Pages <br>
    Проєкт зібраний за допомогою Vite <br>
    Консоль в інструментах розробника не містить помилок, попереджень і консоль логів <br>
    До проєкту підключені бібліотеки iziToast, SimpleLightbox та css-loader <br>
    Елементи на сторінці стилізовані згідно з макетом (або власні стилі) <br>
    У файлі  pixabay-api.js є функція getImagesByQuery(query) для виконання HTTP-запитів <br>
    У файлі render-functions.js створено екземпляр SimpleLightbox та є функції для відображення елементів інтерфейсу: createGallery(images), clearGallery(),  showLoader(),  hideLoader() <br>
    У файлі main.js описана вся логіка роботи додатку <br>
    На сторінці присутня форма пошуку зображень за пошуковим словом <br>
    При сабміті форми перед відправкою запиту на бекенд з’являється індикатор завантаження з css-loader та очищаються попередні результати пошуку на сторінці <br>
    При сабміті форми відправляється запит на бекенд по ключовому слову для пошуку зображень з усіма параметрами, що вказані в ТЗ <br>
    Після отримання відповіді від бекенда зникає індикатор завантаження та на сторінці відмальовуються зображення на основі отриманих даних від бекенду, або з’являється повідомлення про те, що підходящих результатів не було знайдено <br>
    Нові зображення додаються в DOM за одну операцію <br>
    Після додавання нових елементів до списку зображень на екземплярі SimpleLightbox викликається метод refresh() <br>
    При кліку на маленьке зображення в галереї відкривається його збільшена версія у модальному вікні з використанням бібліотеки SimpleLightbox <br>
    Під час виконання HTTP-запитів використовуються обробники then() та catch(), щоб опрацьовувати можливі помилки та запобігти “падінню” сторінки <br>
